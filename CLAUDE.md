# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

Opera Hero — an unmanned, interactive exhibition where visitors mimic
Cantonese Opera gestures in front of a webcam.

## Setup

```bash
npm i
npm run dev
```

## Working conventions in this repo

- **Review every change.** Before editing or creating a file, explain
  what you're about to do and why in plain terms. After the change,
  give a short, clear summary of what was edited and the reasoning
  behind the approach — not just a diff. Don't batch up silent edits
  across multiple files without explanation.
